# 📊 E-Commerce Customer Behaviour & Sales Performance Analysis

## 🔍 Project Overview
End-to-end data analysis project on a real-world e-commerce dataset 
(50,000+ transactions). Performed data cleaning, exploratory data 
analysis (EDA), RFM-based customer segmentation, and built an 
interactive Power BI dashboard to derive actionable business insights.

---

## 🛠️ Tools & Technologies
- **Python** — Pandas, NumPy, Matplotlib
- **SQL** — Cohort analysis, aggregations, grouping
- **Power BI** — Interactive dashboard
- **Excel** — Data validation

## 🔑 Key Insights
- 📈 **Revenue peaked** in November 2011 — strong seasonality trend
- 🌍 **United Kingdom** accounts for ~85% of total revenue
- 👥 **4,338 unique customers** across 18,532 orders
- 💰 **Top 20% of customers** contribute to **65% of total revenue**
- 🎯 Customer segmentation revealed **29% Champions** and 
  **29% Loyal Customers** — strong retention base

---

## 🧠 Methodology

### 1. Data Cleaning
- Removed null CustomerIDs
- Filtered out cancelled orders
- Removed negative quantities and prices
- Created Revenue column (Quantity × UnitPrice)

### 2. Exploratory Data Analysis (EDA)
- Monthly revenue trend analysis
- Top 10 products and countries by revenue
- Order frequency distribution

### 3. RFM Customer Segmentation
| Segment | Description |
|---|---|
| Champions | Bought recently, buy often, spend the most |
| Loyal Customers | Buy regularly with good spending |
| At Risk | Used to buy frequently but not recently |
| Lost | Haven't purchased in a long time |

### 4. Power BI Dashboard
- 3 KPI cards (Revenue, Customers, Orders)
- Monthly Revenue Trend (Line Chart)
- Revenue by Country Top 10 (Bar Chart)
- Customer Segmentation (Donut Chart)
